Política de Privacidad

Octomind Progol · Última actualización: 19 de octubre de 2026

Esta Política de Privacidad describe cómo la aplicación Octomind Progol ("la aplicación", "nosotros") recopila, usa y comparte la información de los usuarios. Al usar la aplicación, aceptas los términos descritos aquí.

1. Información que recopilamos

La aplicación recopila la siguiente información:

  • Correo electrónico: se utiliza como identificador de la cuenta para iniciar sesión.
  • Contraseña: se gestiona de forma segura mediante el servicio de autenticación AWS Cognito; nunca se almacena en texto plano en nuestros servidores.
  • Pronósticos y plantillas personalizadas: las combinaciones y preferencias ("favoritos") que el usuario guarda para los sorteos.
  • Datos biométricos (huella o rostro): se utilizan únicamente en el dispositivo para desbloquear la aplicación. Nunca se envían ni se almacenan en servidores.

2. Cómo usamos la información

Usamos la información para:

  • Autenticar al usuario y permitir el acceso a su cuenta.
  • Guardar y sincronizar sus pronósticos y plantillas personalizadas.
  • Generar el ranking de aciertos entre usuarios.
  • Mejorar el funcionamiento de la aplicación.

3. Servicios de terceros

La aplicación utiliza servicios de Amazon Web Services (AWS) para el almacenamiento y procesamiento de datos (Cognito para autenticación, DynamoDB para almacenamiento y API Gateway/Lambda para la lógica). Estos servicios operan bajo las políticas de seguridad y privacidad de AWS.

4. Compartir información

No vendemos, alquilamos ni compartimos tus datos personales con terceros con fines de marketing. La información solo se procesa a través de los servicios de AWS descritos anteriormente, y únicamente para el funcionamiento de la aplicación.

5. Seguridad de los datos

Implementamos medidas razonables de seguridad para proteger la información, incluyendo el uso de conexiones cifradas (HTTPS) y servicios de autenticación seguros. Sin embargo, ningún método de transmisión o almacenamiento es 100% seguro.

6. Retención de datos

Los datos se conservan mientras el usuario mantenga su cuenta activa. El usuario puede solicitar la eliminación de su cuenta y datos en cualquier momento.

7. Menores de edad

La aplicación no está dirigida a menores de 18 años y no recopila deliberadamente información de menores.

8. Cambios a esta política

Podemos actualizar esta Política de Privacidad periódicamente. La versión más reciente estará siempre disponible en esta página.
